ESTAMOS AQUI PARA AJUDAR

Perguntas frequentes

Informações importantes sobre o funcionamento deste modelo de clínica.

A clínica atende convênios?

Este é um projeto demonstrativo. Em uma clínica real, a lista de convênios aceitos seria informada pela equipe responsável.

Quais são os horários de atendimento?

Os horários serão definidos quando este modelo for adaptado para uma clínica real.

Como faço para agendar uma consulta?

Entre em contato pelo canal informado pela clínica. Nesta demonstração, você pode explorar a interface de agendamento sem enviar dados pessoais.

A consulta é apenas particular?

As modalidades de atendimento dependem da clínica responsável. Consulte as condições antes de confirmar.

Posso remarcar minha consulta?

Em uma clínica real, as regras de remarcação devem ser confirmadas diretamente com a equipe de atendimento.
